# Alcance de la version publica

Esta carpeta contiene una version segura para publicacion abierta.

## Incluye

- concepto general de capa visual de emergencia;
- prototipo visual sin backend;
- identidad segura en nivel conceptual;
- seleccion de incidentes generales;
- derivacion institucional general;
- consola basica de recepcion;
- cierre obligatorio de incidentes;
- principios de seguridad y privacidad.

## No incluye

- flujos sensibles;
- mecanismos operativos internos;
- trazabilidad probatoria detallada;
- procedimientos de monitoreo;
- acceso remoto a sensores;
- capacidades sensibles del dispositivo;
- ubicacion real;
- integraciones reales;
- datos personales;
- instrucciones operativas para casos críticos.

## Recomendacion

La version publica sirve para explicar el valor social, institucional y tecnico del modelo sin exponer capacidades sensibles que deben permanecer en el repositorio privado de trabajo.
