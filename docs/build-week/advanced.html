Principio de arquitectura

Integración sin absorción documental

La consola maestra integra el incidente y puede solicitar aclaraciones, pero no reescribe, elimina, fusiona ni firma actas individuales de otros organismos.

Simulacion multiperspectiva

Etapa 5.1

La misma alerta puede verse como ciudadano, operador de campo, consola federada o consola maestra. El cambio de perspectiva no reinicia el incidente: conserva ID, estado, cronología, actas, evidencia simulada, derivaciones, observaciones y cierre.

Etapa 4A experimental

Secure backend analysis - human validation required. Análisis asistido por IA - requiere validación humana.
