# Master Incident Record

## Objetivo

El Master Incident Record es el expediente digital maestro del incidente. Funciona como indice, sintesis y
mapa de referencias.

No reemplaza las fuentes originales.

## Integra

- ficha del incidente;
- relato original;
- analisis asistido;
- decision humana;
- comparacion IA/humano;
- consolas participantes;
- operadores;
- cronologia;
- actas individuales;
- Acta Digital de Procedimiento;
- versiones;
- evidencia;
- autorizaciones;
- solicitudes de apoyo;
- aclaraciones;
- contradicciones;
- auditoria;
- cierre.

## Regla de autoria

Cada afirmacion debe conservar referencia a:

- acta;
- evento;
- operador;
- consola;
- evidencia;
- fecha.

Si existen diferencias, el expediente muestra:

`Existen versiones o registros que requieren revision.`

No crea una narrativa unica que elimine diferencias.

## Cierre

El expediente se actualiza cuando la consola maestra:

1. genera el acta;
2. ejecuta control de consistencia;
3. obtiene supervision si corresponde;
4. finaliza el acta;
5. propone cierre;
6. cierra el incidente con estado permitido.

Estados de cierre:

- `CLOSED_WITH_REPORT`;
- `CLOSED_WITH_PROCEDURE_ACT`;
- `CLOSED_WITH_EXTERNAL_REFERRAL`;
- `CLOSED_WITH_JUDICIAL_ACTION`;
- `PENDING_FOLLOW_UP`;
- `CANCELLED_WITH_REASON`;
- `FALSE_POSITIVE_WITH_REASON`.

## Limite juridico

La demo demuestra trazabilidad e integridad documental. Su valor juridico definitivo depende de normas,
competencias, firmas, protocolos, auditoria externa y reglas de conservacion aplicables.
