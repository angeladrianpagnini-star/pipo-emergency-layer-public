# Seguridad y privacidad

Esta version publica de PIPO Emergency Layer es una demo conceptual. No procesa emergencias reales ni captura informacion sensible.

## Reglas de publicacion

- No incluir datos personales.
- No incluir procedimientos sensibles de monitoreo.
- No publicar detalles operativos internos.
- No describir mecanismos de acceso remoto a sensores.
- No presentar el sistema como tecnologia lista para uso real.

## Requisitos para una implementacion real

- evaluacion juridica;
- autoridad de aplicacion definida;
- protocolos institucionales;
- autenticacion multifactor;
- control de acceso por rol;
- cifrado en transito y en reposo;
- trazabilidad de acciones;
- minimizacion de datos;
- auditoria;
- politicas de retencion y eliminacion.

## Alcance de la demo

La demo publica no captura datos reales ni accede a sensores del dispositivo. Todo el contenido es simulado.
